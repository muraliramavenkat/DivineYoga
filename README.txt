DivineYoga — LOCAL WEBSITE

1. Extract DivineYoga.zip (right-click → Extract All on Windows, or double-click on Mac).
2. Open the DivineYoga folder.
3. Double-click index.html. Your browser opens the website. No installation or internet is required.
4. Use the navigation for Yin, Vinyasa, Power and Hatha.

Optional localhost address (Python 3 required):
Open a terminal inside the DivineYoga folder and run:
  python3 -m http.server 8000 --bind 127.0.0.1
On Windows use: python -m http.server 8000 --bind 127.0.0.1
Open http://localhost:8000
Stop the server with Ctrl+C.

The folder and site are named DivineYoga; a custom DivineYoga.local address needs additional computer configuration and is not required.

CONTENTS
46 guide illustrations bundled locally; every posture card includes its image. Select any image for an enlarged view.
Four separate style pages: Yin 10, Vinyasa 11, Power 10, Hatha 13 postures plus 8 warm-up drills (46 unique guides), uses, practical benefits, instructions, modifications, precautions, sample sequences, posture search and pauseable hold timer. Printable guides via your browser's Print function.

EDITING
Edit data.js for posture text and sequences, style.css for appearance, app.js for page behaviour. Keep all files together.

PRACTICE
This is an educational personal practice guide, not an individual assessment or medical treatment. Stop for sharp pain, numbness, dizziness or breathlessness. Ask a qualified teacher for unfamiliar poses; seek clinical guidance for injuries, pregnancy, osteoporosis, glaucoma or conditions that affect exercise. Hold times are optional examples, not goals.

BODY-AREA BROWSING
Open Body areas in the navigation. Nine category pages link to 46 shared guide pages. A posture appears under its primary and relevant secondary areas.
Filters: name/muscle search, main action, practice tag, difficulty, yoga style; category pages also filter primary vs secondary involvement. Filters combine, and Clear filters resets them.
No duplicate posture pages are created across categories. All style pages and their hold timers remain available.
CATEGORY_MAP.md contains the posture mapping and naming/image notes. Sanskrit identities that are not established for the exact variation are marked rather than guessed.

EXPANSION
All nine body-area pages contain at least ten relevant guides. Preparatory neck, wrist and ankle drills are clearly marked and can be selected using Guide type. New poses have conservative duration suggestions; follow those rather than applying long Yin holds to every movement. Existing sample sequences remain optional short examples rather than requiring every library entry in one session.

DAILY ROUTINE PLANNER
Open Daily routine in the navigation. Choose a preset, add/reorder/remove guides, adjust timers and print your routine. Changes apply to the open page. Timers do not advance automatically; release and rest before selecting Next.
